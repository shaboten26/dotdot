# dotdot — Pixel Art Studio (v2.5.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵＆ピクセルアニメーション制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要です。懐かしのデジタルガジェット・携帯ゲーム機・レトロ文具をイメージした温かみのあるレトロ可愛い配色（ライト：ウォームアイボリー×ブルーグレー／ダーク：ダスクスレート×グレープ＆セージティール、完全影ゼロ設計）のもと、全数字の `DotGothic16` ドット絵フォント統一・全アイコンのピクセル調統一、広いキャンバス領域と厳格な1行パレットバーを維持したまま、以下の制作機能を提供します。

## v2.5.0 の新機能（全8領域）

### 1. シンメトリー編集（左右対称・上下対称・4方向対称）
- キャンバス中心座標 `((W - 1) / 2, (H - 1) / 2)` を基準に、**奇数サイズ（7×7 等）・偶数サイズ（8×8 等）の両方で1ドット狂いのない対称反射**を計算（奇数サイズ中心上の重複打点を自動排除）。
- **ペン・消しゴム・直線・ベジェ曲線・矩形/楕円・塗りつぶし/グラデーション・スタンプ/パターン**に一貫対応し、1回の描画操作を1ステップで Undo / Redo 可能。
- キャンバス上には非破壊の対称軸ガイドのみを表示（書き出し画像には一切焼き込まれません）。モードバー右端のコンパクトボタンおよびツール「設定」モーダルから即座に切替可能。

### 2. タイルプレビュー（3×3 / 5×5）& シームレス端折り返し編集
- **タイルプレビュー (`OFF` / `3×3` / `5×5`)**: 保存データを一切複製せず、編集キャンバスの周囲にリアルタイムで繰り返し表示。
- **シームレス端折り返し (`OFF` / `左右端接続` / `上下端接続` / `四方向接続`)**: タイル表示とは独立して ON/OFF 可能。ブラシ・直線・図形・スタンプ・塗りつぶし（BFS 4近傍/8近傍）が反対側の端へ `mod W × H` トーラス接続し、継ぎ目のないマップチップやパターン素材を快適に制作できます。

### 3. スプライトシート出力（PNG + JSONメタデータ独立出力）
- アニメーションGIF出力とは独立した出力機能として、作品閲覧画面（`/project/:id`）およびエディタメニューに配置（タイムライン内には配置せずスッキリ維持）。
- **レイアウト**: 横一列 / 縦一列 / 指定列数グリッド、列数・フレーム間余白・外周マージン・整数倍率（ニアレストネイバー）・透過背景維持に対応。
- **レイヤー対象**: 「表示中レイヤーのみ合成（非表示レイヤーは除外）」を標準とし、「単一レイヤーのみ出力」も選択可能。フレーム範囲・再生方向指定にも対応。
- **JSONメタデータ出力**: シートPNGとは別ボタンで、Aseprite JSON Array 互換フォーマット（Unity / Godot / Phaser / PixiJS 等でそのまま利用可能）＋ `dotdot` 固有情報（`canvasSize`, `sheetSize`, `scale`, `grid`, フレーム別座標・サイズ・`durationMs`）を保存可能。

### 4. Aseprite 形式（`.ase` / `.aseprite`）オフライン入出力
- 外部サーバー不要・`fflate` ZLIB 圧縮を用いた純 TypeScript 製リトルエンディアン・バイナリパーサー＆エンコーダー（Magic `0xA5E0` / Frame `0xF1FA` / Layer `0x2004` / Cel `0x2005` Raw・ZLIB・Linked / Palette `0x2019`・`0x0004`・`0x0011` / sRGB `0x2007`）。
- **リンクセル双方向保持**: Aseprite の `Linked Cel (celType = 1)` と dotdot の共有 `celId` (`CelMap`) を双方向に変換し、データ重複なく共有構造を維持。
- **明示的互換確認UI**: レイヤーグループ、タイルマップ、未対応合成モード、タグ、スライス、256px超過などが含まれる場合は無断破棄せず読み込み前モーダルで明示警告を表示。破損バイナリも安全にエラーハンドリングします。

### 5. PNG画像読み込み & 元ドット解像度の自動復元
- **PNG `tEXt` メタデータ埋め込み (`dotdot-meta`)**: dotdot からの拡大PNG出力時に元解像度と整数倍率を記録（設定画面およびPNG出力モーダルで ON/OFF 可能）。再読み込み時も実際の画素ブロック均一性と照合し、外部ソフトで1×加筆・ぼかしされた画像を誤縮小しない保護機構を搭載。
- **外部拡大ドット絵の整数ブロック自動検出**: メタデータがない外部PNGでも `gcd(W, H)` の約数から厳密に均一な `k × k` ピクセルブロックを検出し、確認モーダル上で Before/After サイズとプレビューを比較しながら **「元解像度で読み込む」／「元のPNGサイズのまま読み込む」／候補倍率** を選択可能。
- **新規作品作成**（一覧画面・エディタ）および **現在の作品への新規レイヤー追加**（エディタ）の両方に対応。

### 6. パレットの知覚順並べ替え・色使用分析・色置換
- **厳格な1行 `PaletteBar` 維持**: 画面下部の1行パレットバーは一切変更せず、パレットシート内の単一ボタン **「整理・分析」** に集約。
- **知覚的 CIELAB (`L*a*b*`) 並べ替え & 元の順番へ戻す**: 明度順（暗→明 / 明→暗）・色相順・彩度順で並べ替え可能。左端の透明スロット（`-1`）は固定し、選択中の色も追従。並べ替えだけではキャンバスのドット色は一切変化せず、ワンタップで元の並び順へ復元できます。
- **色使用分析（読み取り専用）**: 表示レイヤー合成または選択レイヤー単体での使用色数・不透明ドット数・各色のドット数と比率(%)・未使用パレット色を一覧表示。
- **リンクセル維持の色置換**: 作品全体（全セル・全レイヤー）／現在フレーム／現在レイヤーを対象に指定色を別色または透明へ一括置換。共有 `celId` ごとに1回だけ処理するためリンクセルが解除されず、1ステップで Undo / Redo 可能。

### 7. ピクセルスタンプ & パターンブラシ
- 選択範囲のピクセルを名前付き `StampAsset` として IndexedDB の独立ストア（Dexie v4 `stamps`）へ保存（初期プリセット5種同梱、作品を削除してもスタンプは独立保持され、環境パック ZIP の書き出し・復元対象にも含まれます）。
- **1×等倍・透明維持スタンプ配置**: ライブプレビュー付きで1px単位移動・ドラッグ・左右/上下反転して配置でき、スタンプ内の透明ピクセルが下地を上書きしません（Undo / Redo 対応）。
- **パターンペン描画**: 登録スタンプをタイリングモチーフとしてペンストロークで連続描画可能。

### 8. UIアニメーション & View Transition の根本改善
- `document.startViewTransition` 内で `flushSync` による同期DOM確定を行うことで、作品一覧 ⇄ 作品閲覧 ⇄ エディタ間の共有要素 (`artwork-${id}`) View Transition とフォールバックアニメーションの競合を解消。
- `transform` / `opacity` 中心の `200〜280ms` トランジション、`image-rendering: pixelated` 維持、`prefers-reduced-motion` 完全対応、エディタ操作中の `<canvas>` 再マウント防止を徹底。

## データ構造・ストレージ設計

- **保存先**: ブラウザ内 IndexedDB (`Dexie` `DotDotDatabase` **v4**) — 外部サーバー・クラウドDB不使用
  - `projects`: 作品メタデータ・レイヤー構成・パレット（`originalColors` 含む）・タイムライン（`frames`, `cels` 等）
  - `celBuffers`: セル単位のユニーク RGBA バッファ (`${projectId}:${celId}`)
  - `layerPixels`: 後方互換・フォールバック用レイヤー画素ストア
  - `histories`: セル差分パッチ・構造スナップショット・ワールド座標選択状態を含む Undo/Redo 履歴
  - `palettes`: カスタム＆Lospec インポートパレット
  - `stamps`: 作品から独立して永続化されるピクセルスタンプ＆パターン資産（v4 新設・環境パック ZIP 対象）
  - `settings`: UI スケール・テーマ・言語・履歴上限・シンメトリー/シームレス初期値・PNGメタデータ埋め込み設定等
