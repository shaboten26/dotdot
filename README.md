# dotdot — Pixel Art Studio (v2.2.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵＆ピクセルアニメーション制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要です。低彩度カーボン×レトロデジタルツール調のフラット UI（完全影ゼロ設計）のもと、最大 256×256px・50 レイヤー・1フレーム静止画と複数フレーム（空セル・独立セル・リンクセル）を単一モデルで扱うタイムライン、オニオンスキン、オフライン純 TypeScript 製 GIF89a アニメーション書き出し、Lospec パレットインポート、長辺最大 4000px（初期選択 約2000px）PNG 出力＆OS共有シート、環境パック ZIP バックアップまで一貫して提供します。

## 主な実装済み機能

### 1. 静止画（1フレーム）× アニメーション（Nフレーム）統合セルアーキテクチャ
- **単一データモデル（Dexie v3 `celBuffers`）**:
  - 1フレーム静止画と複数フレームアニメーションを同一のレイヤー×フレーム×セル構造で統合。
  - **空セル (`celId = null`)** はメモリ・保存容量 `0 B`、**独立セル**は固有バッファ、**リンクセル**は複数フレーム間で同一 `celId` の RGBA バッファを共有（重複保存なし）。
  - リンクセルへの描画は共有先フレームすべてに即時同期され、**1回の「元に戻す」**で全リンク先フレームが一括で元に戻ります。空セルへの描画は自動的に新規独立セルを割り当て、「元に戻す」で空セルへ復帰します。
- **常時キャンバス表示のワークスペース切替**:
  - 下部モードバーで **`ツール`** と **`レイヤー`（1フレーム時）／`タイムライン`（2フレーム以上時）** をワンタップ切替。`レイヤー` タブからフレーム追加／複製を行うとシームレスに `タイムライン` マトリクスへ移行します（アニメーションタグ機能は意図的に非搭載）。
- **レイヤー×フレーム セルマトリクス & 再生・オニオンスキン**:
  - セル単位のリンク化・独立化（リンク解除）・空セル化・コピー＆ペースト（独立／リンク）・複数セル選択一括操作に対応。
  - フレームごとのミリ秒（`ms`）指定および全フレーム／選択フレームへの一括 `ms` 適用、再生方向（順方向 `→` / 逆方向 `←` / 往復ピンポン `↔`）、ループ／1回再生、再生速度（`0.25x`〜`4x`）、前後フレーム色分けオニオンスキン（枚数・不透明度調整）を搭載。

### 2. 完全オフライン純 TypeScript 製 GIF89a エンコーダ (`src/engine/gifEncoder.ts`)
- **外部通信ゼロ・透過ゴースト防止 (`Disposal Method = 2`)**:
  - 透過ドット絵アニメーションで前フレームの残像が残らないよう Graphic Control Extension の Disposal Method 2（背景色クリア）と透過色インデックスを厳格出力。
- **半透明画素の 2 モード処理 & 最大 256 色量子化**:
  - レイヤー不透明度やブレンドによる半透明画素を **4×4 Bayer ディザ透過 (`dither`)** または **背景マット合成 (`matte`、任意背景色)** から選択可能。
  - 255色＋透過1色に収まる場合は完全一致パレットを維持し、超過時のみ Median-Cut 量子化を自動適用。
- **整数倍拡大（長辺最大 4000px / 初期値 約2000px）・再生方向・進捗＆中断・OS共有**:
  - ニアレストネイバー整数倍拡大、順方向／逆方向／往復（端点重複なし）、無限ループ（`NETSCAPE2.0`）／1回再生、`10ms (1cs)` 単位丸め注記、非同期プログレスバー＆中断ボタン、ダウンロードおよび Web Share API 共有に対応。

### 3. スマートフォン親指操作 × PCマウス直接描画の最適化 & UX 改善
- **入力モダリティ自動適応**:
  - スマートフォン／タッチ操作時は画面スライドによる仮想カーソル移動＋下部固定「描く」ボタンで親指操作を快適化。
  - PCマウス操作時は仮想カーソルと下部「描く」ボタンを自動非表示にし、OSマウスカーソルによる直接クリック＆ドラッグ描画とキーボードショートカット（`B`/`E`/`G`/`L`/`U`/`M`/`I`、`,`/`. ` フレーム移動、`Ctrl/Cmd+Z` 等）で軽快に動作。
- **コンパクト半透明＋ブラーのツール詳細ポップオーバー**:
  - 選択中ツールの再タップで開く詳細設定を、キャンバス視認性を妨げない半透明＋背景ブラー（影ゼロ）のコンパクトポップオーバーとして表示。
- **描画・選択・レイヤー・パレットの細部 UX**:
  - **二回タップスポイトのカーソル座標サンプル**: 素早いダブルタップ時、タップ位置ではなく**現在のアプリ内カーソル座標**の色（透明含む）を誤描画ゼロで取得。
  - **バケツ／グラデーションの明確なアイコン分離 & ディザ密度による円形グラデーション**: 半透明アルファを一切出さず、パレット色×ディザ密度のみで綺麗な円形／楕円（1:1比率固定対応）グラデーションを描画。
  - **画面外（ワールド座標）選択状態・画素の完全保持**: 選択範囲をキャンバス外へ一部／完全に移動しても選択枠・画素データが消滅せず、再度キャンバス内へ戻す操作や Undo/Redo が非破壊で機能。
  - **レイヤー名変更とドラッグ並び替えの完全分離**: ダブルクリック／ダブルタップでのリネーム開始時にドラッグ誤発火を防止し、編集開始時に既存名を自動全選択。
  - **パレット名入力欄フォーカス時の自動全選択**および最左端固定の**専用「透明色」スロット (`TRANSPARENT_COLOR_INDEX = -1`)**。

### 4. Lospec パレットインポート & 規約・OSSライセンス表示
- **Lospec 公式 JSON API 連携 (`https://lospec.com/palette-list/<slug>.json`)**:
  - Lospec のパレット URL またはスラッグを入力するだけでパレット名・作者名・色数・カラースウォッチをプレビューし、現在の作品パレットの**置き換え**／**末尾追加**（256色上限・重複除外）やパレットライブラリへの保存が可能。保存後はオフラインでも利用でき、作者・出典メタデータも保持します。
- **利用規約・プライバシーポリシー・ソースコード／OSSライセンス**:
  - 設定画面からいつでも3タブ構成の規約・ローカルデータ保護方針・GitHub リポジトリ (`https://github.com/shaboten26/dotdot`) および使用 OSS ライセンス一覧（日・英・韓対応）を確認可能。

### 5. 履歴上限デフォルト「無制限」・単一作品データ容量・Origin 容量低下警告
- **Undo 履歴上限の初期値 `'unlimited'`**: 作品制作中の自由な試行錯誤を優先し、新規環境のデフォルトを「無制限」に設定（設定画面で `20 / 50 / 100 / 無制限` から任意変更可、ストレージ逼迫時は古い履歴から安全に自動トリム）。
- **単一作品のデータ容量（概算）表示**: 作品閲覧画面 (`/project/:id`) に、Origin 全体使用量ではなく**その作品1件の概算データ容量**（メタデータ＋ユニークセルバッファ＋対象作品履歴）とフレーム数を正確に表示。
- **ブラウザ保存領域（Origin）残量低下時の環境パック ZIP バックアップ誘導**: `navigator.storage.estimate()` に基づき残量逼迫時のみギャラリー・設定画面で控えめに通知し、環境パック ZIP（全セル・タイムライン・パレット・プリセット含む完全ラウンドトリップ対応）への退避を案内。

## データ構造・ストレージ設計

- **保存先**: ブラウザ内 IndexedDB (`Dexie` `DotDotDatabase` v3) — 外部サーバー・クラウドDB不使用
  - `projects`: 作品メタデータ・レイヤー構成・パレット・タイムライン（`frames`, `cels`, `playbackDirection`, `loopPlayback` 等）
  - `celBuffers`: セル単位のユニーク RGBA バッファ (`${projectId}:${celId}`)
  - `layerPixels`: 後方互換・フォールバック用レイヤー画素ストア
  - `histories`: セル割り当て情報 (`celAllocation`)・ワールド座標選択状態を含む Undo/Redo 履歴
  - `palettes`: カスタム＆Lospec インポートパレット（作者・出典メタデータ含む）
  - `settings`: UI スケール・テーマ・言語・履歴上限・カスタムサイズプリセット等
