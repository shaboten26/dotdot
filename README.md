# dotdot — Pixel Art Studio (v2.4.1)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵＆ピクセルアニメーション制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要です。懐かしのデジタルガジェット・携帯ゲーム機・レトロ文具をイメージした温かみのあるレトロ可愛い配色（ライト：ウォームアイボリー×ブルーグレー／ダーク：ダスクスレート×グレープ＆セージティール、完全影ゼロ設計）のもと、全数字のドット絵フォント統一・全アイコンのピクセル調統一、ネイティブアプリライクなスプリングモーション＆View Transition API、最大 256×256px・最大 100 レイヤー・フレーム数上限なし・1フレーム静止画と複数フレーム（空セル・独立セル・リンクセル）を単一モデルで扱うタイムライン、異なる作品のキャンバス間でのコピー＆ペースト、後から既存セルをリンクセルへ変更できる参照管理、ツールタブ・タイムラインタブ共通のモードバー内フレーム再生・前後移動コントロール、全体設定内の非破壊反転プレビュー、オフライン純 TypeScript 製 GIF89a アニメーション書き出し、Lospec パレットインポート、長辺最大 4000px（初期選択 2000px以下の最大整数倍）PNG/GIF 出力＆OS共有シート、環境パック ZIP バックアップまで一貫して提供します。

## 主な実装済み機能

### 1. 静止画（1フレーム）× アニメーション（Nフレーム）統合セルアーキテクチャ & 後付けリンクセル
- **単一データモデル（Dexie v3 `celBuffers`）**:
  - 1フレーム静止画と複数フレームアニメーションを同一のレイヤー×フレーム×セル構造で統合（最大 100 レイヤー、アプリの固定フレーム数上限なし＋構成負荷に応じた非阻害型注意表示）。
  - **空セル (`celId = null`)** は保存容量 `0 B`、**独立セル**は固有バッファ、**リンクセル**は複数セル間で同一 `celId` の RGBA バッファを共有（重複保存なし）。
- **常時キャンバス表示のワークスペース切替 & モードバー常駐フレーム操作コントロール**:
  - 下部モードバーで **`ツール`** と **`レイヤー`（1フレーム時：従来のレイヤー管理UIを再利用）／`タイムライン`（2フレーム以上時：簡潔なタイムラインUI）** をスプリングピルアニメーション付きで切り替え（アニメーションタグ機能は意図的に非搭載）。
  - 2フレーム以上のアニメーション時は、`ツール` タブ選択時・`タイムライン` タブ選択時の両方で、モードバー右側に **前フレーム (`◀`)・再生/一時停止＋現在フレーム番号 (`1/3`)・次フレーム (`▶`)** のコンパクトコントロールを一貫表示し、タイムライン内部の冗長なステータスバッジや重複再生ドックを排除して広いキャンバス領域を維持します。
- **既存セルを後からリンクセルへ変更・参照先変更 (`LinkCelModal`)**:
  - 既存の独立セルや空セルを選択し、セルメニューから **「リンクセルに変更」**（既にリンクセルの場合は **「参照先を変更」**）を実行可能。
  - 参照元セル候補のサムネイル・フレーム番号・レイヤー名・現在の共有状況を確認し、変更前後のプレビューを比較したうえで適用可能。
  - 対象セルに参照元と異なる画像データがある場合は、置き換え前に必ず確認ダイアログを表示。確定後も **Undo / Redo で元の独立セルの画像データと参照関係を100%復元** できます。
- **スクロール可能なアニメーション設定モーダル (`AnimationSettingsModal`)**:
  - スマートフォンではセーフエリア対応の大型ボトムシート、PCでは中央ダイアログとして開き、モーダル内部スクロール（`overscroll-contain`）で再生方式・フレーム表示時間（個別／初期値／一括）・オニオンスキン・セル統計の最下部まで確実に操作可能（キャンバス領域を縮小しません）。

### 2. ツールタブ内の全体設定（非破壊反転プレビュー・仮想カーソル速度・表示サイズ）& ネイティブライクなモーション
- **独立タブを増やさず旧レイヤー管理枠を活用**:
  - ツールタブ内の2行目右端枠に正しい8方向歯車ドット絵アイコンの **「設定」** ボタンを配置（アニメーション設定や各ツール固有設定は混在させず、編集・表示環境・入力全体に共通する設定のみを収録）。
- **非破壊の左右反転・上下反転プレビュー**:
  - 実際のドットデータや PNG/GIF 書き出し結果を一切変更せず、ビューポート表示と入力座標のみを鏡像反転（左右反転・上下反転・ワンタップ標準向きリセット＆キャンバス左上ステータスバッジ付き）。
- **ネイティブアプリライクな滑らかモーション (`motion/react` & `<ViewTransition>`)**:
  - タブ・カラーモード・テーマ・UIプリセット・ツール選択の `layoutId` スライディングハイライト、ボトムシート／モーダル／ポップオーバーの軽快なスプリングアニメーション、作品カードから閲覧・編集画面への共有要素 View Transition に対応（`prefers-reduced-motion` 設定も尊重）。
- **全数字の `DotGothic16` ドット絵フォント統一 & 全アイコンのピクセル調統一**:
  - `--font-sans`・`--font-mono`・フォーム入力（`<input>` / `<input type="number">`）・バッジ・ボタン・SVGラベルのすべてで視認性の高い **`DotGothic16`** を最優先適用し、フレーム番号・座標・サイズ・倍率・設定値・容量まで日本語テキストと調和した読みやすいドット絵フォントで統一。
- **スマートフォン仮想カーソル設定（マウスカーソル変更機能は非搭載でシンプル化）**:
  - **カーソル速度**: スライダー（`0.25x`〜`3.00x`）およびプリセット（低速・標準・高速）で調整可能。サブピクセル蓄積により画素単位の描画精度を維持。
  - **カーソル表示サイズ**: 小・標準・大を切替可能（PCマウス操作時は標準カーソルを使用）。
  - **ダブルタップスポイト ON/OFF**: スポイト詳細設定・設定画面と同一の設定状態を共有。

### 3. 完全オフライン純 TypeScript 製 GIF89a エンコーダ & 作品閲覧体験
- **初期出力サイズ `floor(2000 / 長辺)` 倍（PNG・GIF共通）**:
  - 長辺 2000px 以下で最も近い整数倍（例：`256px → 7倍=1792px`、`128px → 15倍=1920px`、`80px → 25倍=2000px`）を初期選択とし、長辺最大 4000px までニアレストネイバー拡大出力に対応。
- **GIF出力の表示制御**:
  - 2フレーム以上のアニメーション作品でのみ GIF 出力を表示し、タイムライン内からは除外して作品閲覧画面・エディタ書き出しメニューに整理。
  - `Disposal Method = 2`、半透明画素の 4×4 Bayer ディザ透過／背景マット合成、進捗表示＆中断に対応。
- **作品閲覧画面 (`/project/:id`) のソリッド背景表示 & 左右スワイプ作品切り替え**:
  - 閲覧画面のプレビュー背面は市松模様ではなく画面背景色（`--bg-app`）と同一のソリッド背景でスッキリ鑑賞可能。
  - ギャラリーの現在の並び順（手動・更新順・作成順・名前順）を維持したまま左右スワイプで前後の作品へスプリング遷移でき、隣接作品の先読みキャッシュと誤反応防止に対応。

### 4. 選択範囲・作品間コピー＆ペースト・グラデーション・パレット・バックアップ
- **アニメーションするマーチングアンツ・選択範囲内描画の Undo 保持・作品間コピー＆ペースト**:
  - **動く境界点線（マーチングアンツ）**: 連結された境界辺に沿ってスクリーンピクセル空間で位相を進めることで、どのズーム倍率・複雑な形状でも滑らかに点線がアニメーションします（画素データには一切焼き込まれません）。
  - **選択範囲を維持した描画 Undo**: 選択範囲を作成した状態で直線・ペン・塗りつぶし・図形などを描画した後に「元に戻す（Undo）」を押すと、描画した内容のみが取り消され、選択範囲はそのまま維持されます。
  - **異なる作品（キャンバス）間のコピー＆ペースト**: ある作品のキャンバスでコピー／切り取りしたピクセルデータを、別の作品のキャンバスを開いてそのまま貼り付け可能（貼り付け先のキャンバスサイズに合わせて画面外にならないよう自動補正）。
- **円形ディザグラデーション**: アルファ半透明を使わず、ディザ密度変化のみで中心から外側へ段階的に疎になる円形／楕円グラデーションを描画。
- **Lospec 公式 JSON API パレットインポート & 利用規約・プライバシー・OSSライセンス表示**。
- **Undo 履歴デフォルト「無制限」・作品単体の概算データ容量表示・Origin 容量低下警告・環境パック ZIP 完全バックアップ**。
- **iPhone ホーム画面 PWA 起動時の上部プログレッシブブラー根本抑止**。

## データ構造・ストレージ設計

- **保存先**: ブラウザ内 IndexedDB (`Dexie` `DotDotDatabase` v3) — 外部サーバー・クラウドDB不使用
  - `projects`: 作品メタデータ・レイヤー構成・パレット・タイムライン（`frames`, `cels`, `playbackDirection`, `loopPlayback` 等）
  - `celBuffers`: セル単位のユニーク RGBA バッファ (`${projectId}:${celId}`)
  - `layerPixels`: 後方互換・フォールバック用レイヤー画素ストア
  - `histories`: セル割り当て情報・構造スナップショット・選択変更時のみ記録されるワールド座標選択状態を含む Undo/Redo 履歴
  - `palettes`: カスタム＆Lospec インポートパレット（作者・出典メタデータ含む）
  - `settings`: UI スケール・テーマ・言語・履歴上限・仮想カーソル速度／サイズ・カスタムサイズプリセット等

## 開発・ビルド・テスト手順

```bash
# TypeScript 厳格型チェック
npm run typecheck

# Vitest 単体・結合・UI E2E テスト実行
npm test

# 本番ビルド（PWAアイコン生成 → TypeScript/Viteビルド → オフラインSW dist/sw.js 生成）
npm run build

# ローカルプレビュー（Cloudflare Pages 静的配信互換）
npx wrangler pages dev dist --ip 0.0.0.0 --port 3000
```
