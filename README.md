# dotdot — Pixel Art Studio (v2.3.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵＆ピクセルアニメーション制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要です。柔らかく親しみやすい低彩度カーボン×ラベンダー／セージ調のフラット UI（完全影ゼロ設計）のもと、最大 256×256px・最大 100 レイヤー・フレーム数上限なし・1フレーム静止画と複数フレーム（空セル・独立セル・リンクセル）を単一モデルで扱うタイムライン、後から既存セルをリンクセルへ変更できる参照管理、オニオンスキン、オフライン純 TypeScript 製 GIF89a アニメーション書き出し、Lospec パレットインポート、長辺最大 4000px（初期選択 2000px以下の最大整数倍）PNG/GIF 出力＆OS共有シート、環境パック ZIP バックアップまで一貫して提供します。

## 主な実装済み機能

### 1. 静止画（1フレーム）× アニメーション（Nフレーム）統合セルアーキテクチャ & 後付けリンクセル
- **単一データモデル（Dexie v3 `celBuffers`）**:
  - 1フレーム静止画と複数フレームアニメーションを同一のレイヤー×フレーム×セル構造で統合（最大 100 レイヤー、アプリの固定フレーム数上限なし＋構成負荷に応じた非阻害型注意表示）。
  - **空セル (`celId = null`)** は保存容量 `0 B`、**独立セル**は固有バッファ、**リンクセル**は複数セル間で同一 `celId` の RGBA バッファを共有（重複保存なし）。
- **常時キャンバス表示のワークスペース切替**:
  - 下部モードバーで **`ツール`** と **`レイヤー`（1フレーム時：従来のレイヤー管理UIを再利用）／`タイムライン`（2フレーム以上時：簡潔なタイムラインUI）** を切り替え（アニメーションタグ機能は意図的に非搭載）。
- **既存セルを後からリンクセルへ変更・参照先変更 (`LinkCelModal`)**:
  - 既存の独立セルや空セルを選択し、セルメニューから **「リンクセルに変更」**（既にリンクセルの場合は **「参照先を変更」**）を実行可能。
  - 参照元セル候補のサムネイル・フレーム番号・レイヤー名・現在の共有状況を確認し、変更前後のプレビューを比較したうえで適用可能。
  - 対象セルに参照元と異なる画像データがある場合は、置き換え前に必ず確認ダイアログを表示。確定後も **Undo / Redo で元の独立セルの画像データと参照関係を100%復元** できます。
- **スクロール可能なアニメーション設定モーダル (`AnimationSettingsModal`)**:
  - スマートフォンではセーフエリア対応の大型ボトムシート、PCでは中央ダイアログとして開き、モーダル内部スクロール（`overscroll-contain`）で再生方式・フレーム表示時間（個別／初期値／一括）・オニオンスキン・セル統計の最下部まで確実に操作可能（キャンバス領域を縮小しません）。

### 2. ツールタブ内の全体設定（カーソル速度・表示サイズ・カスタムカーソル編集）
- **独立タブを増やさず旧レイヤー管理枠を活用**:
  - ツールタブ内の2行目右端枠に歯車アイコンの **「設定」** ボタンを配置（アニメーション設定や各ツール固有設定は混在させず、編集環境・入力全体に共通する設定のみを収録）。
- **カーソル操作カスタマイズ（スマートフォン仮想カーソル向け）**:
  - **カーソル速度**: スライダー（`0.25x`〜`3.00x`）およびプリセット（低速・標準・高速）で調整可能。サブピクセル蓄積により画素単位の描画精度を維持。
  - **カーソル表示サイズ**: 小・標準・大を切替可能（実際の描画座標やブラシサイズには非影響）。
  - **カーソルデザイン & カスタムカーソル編集**: 標準カーソルに加え、`8×8` / `16×16` グリッドで自作ドット絵カーソル（ペン・消しゴム・矢印／十字テンプレ・名前保存・複数切替）を作成可能。カーソルごとに **基準点（ホットスポット）** を指定でき、高視認性アウトライン付きで描画位置と正確に一致します（PCマウス操作時は従来どおりOS標準マウスカーソルを使用）。
  - **ダブルタップスポイト ON/OFF**: スポイト詳細設定・設定画面と同一の設定状態を共有。

### 3. 完全オフライン純 TypeScript 製 GIF89a エンコーダ & 出力・作品閲覧体験
- **初期出力サイズ `floor(2000 / 長辺)` 倍（PNG・GIF共通）**:
  - 長辺 2000px 以下で最も近い整数倍（例：`256px → 7倍=1792px`、`128px → 15倍=1920px`、`80px → 25倍=2000px`）を初期選択とし、長辺最大 4000px までニアレストネイバー拡大出力に対応。
- **GIF出力の表示制御**:
  - 2フレーム以上のアニメーション作品でのみ GIF 出力を表示し、タイムライン内からは除外して作品閲覧画面・エディタ書き出しメニューに整理。
  - `Disposal Method = 2`、半透明画素の 4×4 Bayer ディザ透過／背景マット合成、進捗表示＆中断に対応。
- **作品閲覧画面 (`/project/:id`) の左右スワイプ作品切り替え**:
  - ギャラリーの現在の並び順（手動・更新順・作成順・名前順）を維持したまま左右スワイプで前後の作品へ移動でき、隣接作品の先読みキャッシュと誤反応防止（縦スクロール・ピンチズーム分離）に対応。

### 4. 選択範囲・グラデーション・パレット・バックアップ
- **選択範囲の「移動開始」分離・1px矢印移動・マーチングアンツ**:
  - 選択確定後に「移動開始」を押してからコンパクトな1行移動バー（1px単位の上下左右矢印ボタン・長押し連続移動対応）へ移行。動く点線（マーチングアンツ）はオーバーレイ専用で画素データに一切焼き込まれず、キャンバス外へ出た選択範囲も内部保持します。
- **円形ディザグラデーション**: アルファ半透明を使わず、ディザ密度変化のみで中心から外側へ段階的に疎になる円形／楕円グラデーションを描画。
- **Lospec 公式 JSON API パレットインポート & 利用規約・プライバシー・OSSライセンス表示**。
- **Undo 履歴デフォルト「無制限」・作品単体の概算データ容量表示・Origin 容量低下警告・環境パック ZIP 完全バックアップ**。
- **iPhone ホーム画面 PWA 起動時の上部プログレッシブブラー根本抑止**:
  - `apple-mobile-web-app-status-bar-style="default"` とテーマ連動 `meta[name="theme-color"]` に加え、iOS スタンドアロン PWA 起動時のみヘッダー背面のソリッド固定キャップ（`.ios-pwa-top-solid-cap`）と最上位クリップスロット（`.ios-pwa-top-blur-fix`）を適用し、通常の Safari ブラウザ・Android・PC 表示に一切影響を与えずに上端ブラーとステータスバー文字被りを防ぎます。

## データ構造・ストレージ設計

- **保存先**: ブラウザ内 IndexedDB (`Dexie` `DotDotDatabase` v3) — 外部サーバー・クラウドDB不使用
  - `projects`: 作品メタデータ・レイヤー構成・パレット・タイムライン（`frames`, `cels`, `playbackDirection`, `loopPlayback` 等）
  - `celBuffers`: セル単位のユニーク RGBA バッファ (`${projectId}:${celId}`)
  - `layerPixels`: 後方互換・フォールバック用レイヤー画素ストア
  - `histories`: セル割り当て情報・構造スナップショット・ワールド座標選択状態を含む Undo/Redo 履歴
  - `palettes`: カスタム＆Lospec インポートパレット（作者・出典メタデータ含む）
  - `settings`: UI スケール・テーマ・言語・履歴上限・カーソル設定＆カスタムカーソル・カスタムサイズプリセット等

## 開発・ビルド・テスト手順

```bash
# TypeScript 厳格型チェック
npm run typecheck

# Vitest 単体・結合・UI E2E テスト実行
npm test

# 本番ビルド（PWAアイコン生成 → TypeScript/Viteビルド → オフラインSW dist/sw.js 生成）
npm run build

# ローカルプレビュー（Cloudflare Pages 静的配信互換）
npx wrangler pages dev dist --ip 0.0.0.0 --port 3000
```
