# dotdot — Pixel Art Studio (v2.0.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵制作 Web アプリケーションです。

外部サーバーへのデータ送信やアカウント登録は一切不要で、低彩度レトロデジタルツール調の落ち着いた UI のもと、最大 256×256px・50 レイヤー・ディザリング・ピクセルパーフェクト3次ベジェ曲線・非破壊図形回転・環境パック ZIP バックアップまで一貫して提供します。

## 主な実装済み機能（仕様 v1 + 追加仕様 v2 完全準拠）

### 1. レトロかわいい・落ち着いた低彩度ドット絵デザイン（v2）
- **ダーク／ライト両対応の低彩度カラーシステム**: ダークは落ち着いたダークプラム／スレート系 (`#181521` / `#221e2e`)、ライトはウォームストーン系 (`#e9e5dc` / `#f4f1ea`)、アクセントはラベンダー・セージティール・ダスティローズを採用。
- **オフライン同梱ピクセルフォント**: `@fontsource/dotgothic16` および `@fontsource/silkscreen` をローカルバンドルし、オフラインでもドット絵フォントを維持。
- **40種以上のカスタム 16×16 ドット絵 SVG アイコン (`PixelIcon`)**: 汎用ベクターアイコン（Lucide 等）を全廃し、すべて `shape-rendering="crispEdges"` のオリジナルドット絵アイコンとピクセル枠・段積みオフセット影・ピクセルチェックボックス (`PixelCheckbox`) で統一。
- **色だけに頼らない状態表現**: 選択色・有効ツール・ON/OFF 状態は二重ピクセル枠、ピクセルチェックマーク、段落ち押し込み表現を併用。

### 2. ドットピクト風レイアウト & 再タップ詳細パネル（v2）
- **起動時の標準ホームは作品一覧 (`/`)**: 初回起動時に空キャンバスを勝手には開かず、作品 0 件時はピクセルアートのイーズルイラストと「最初の作品をつくる」CTA を表示。
- **4段構成エディタレイアウト**:
  1. 画面の主役となる広いキャンバス（2本指ピンチズーム＆パン、ホイールズーム対応）
  2. アイコン＋短い名前付きの2段ツールグリッド（44px 以上のタップ領域）
  3. 選択色チェックバッジ付きパレットバー
  4. 画面下部の超大型「**描く / Draw / 그리기**」プッシュボタン（標準 `15dvh`、Safe Area 対応）
- **選択中ツールの再タップによる詳細設定開閉**:
  - 小さな専用設定ボタンを置かず、未選択ツールは 1 回目タップでツール切替、**すでに選択中のツールをもう一度タップするとコンパクトなフロート詳細ポップオーバーが開閉**。
  - 詳細ポップオーバー表示中もキャンバス縮小なし・カーソル非表示なし・そのまま「描く」ボタンで描画可能。

### 3. ピクセルアート描画エンジン (`src/engine/*`)
- **ペン / 消しゴム**: サイズ `1〜32px`、形状（四角 / 丸）、`(0,0)` 原点固定の **8段階ディザパターン**、独立実装の L 字角除去 **ピクセルパーフェクト**（デフォルト ON）。
- **塗りつぶし & 単色濃度グラデーション塗り**:
  - 4方向 / 8方向隣接、ディザパターン維持塗り（`.` 画素を元のまま保持）。
  - 始点→終点ベクトルのスカラー射影に基づく **4段階 `[1,4,6,8]` / 8段階 `[1..8]` 単色濃度グラデーション塗り**（連結領域内限定・ライブプレビュー完全一致）。
- **直線 & ピクセルパーフェクト 3次ベジェ曲線（v2 強化）**:
  - `P0 -> P3 -> P1 -> P2` の 4 ステップ操作とハンドル可視化。
  - **サイズ 1px**: 2パス走査＋L字角除去＋単一画素突起抑制により、2×2 の塊やアンチエイリアスを一切出さない滑らかな 1px ピクセルパーフェクト曲線を描画。
  - **サイズ 2px 以上**: サイズ 1px のピクセルパーフェクト中心線を先に生成し、その中心線に沿って丸／四角ブラシスタンプで太らせる二段階ラスタライズ。
- **図形（四角・円/楕円）& 非破壊回転トランスフォーム**:
  - 1:1 固定比率 `PixelCheckbox`、単一の「塗りつぶし」`PixelCheckbox`。
  - 配置直後にフロート変形モードへ移行し、元図形バッファからの逆写像ニアレストネイバー法による `-90° / +90° / -5° / +5°` 回転（累積劣化ゼロ・アンチエイリアスゼロ）と 1px 移動・ドラッグ移動・確定／破棄が可能。
- **選択ツール**: 自動選択（4/8方向）、矩形、楕円、追加選択（Union）、選択反転、解除、1px 移動、2種アルゴリズム（通常8近傍 / ピクセルパーフェクト4近傍）の選択範囲アウトライン、切り取り・コピー・貼り付け、左右/上下反転。
- **ツール別ドット絵カーソル & 表示倍率連動タッチ速度**:
  - ツールごとに固有のドット絵カーソルを描画。
  - タッチドラッグ時は `dxCss / transform.scale` により画面上の指の移動距離に比例した速度で動き、サブピクセル端数を保持したまま整数ピクセル座標へスナップ。

### 4. レイヤー（最大 50 枚）& パレット管理
- **レイヤー**: 最大 50 枚、不透明度 `0〜100%`、下のベースレイヤーへのクリッピングマスク、8種ブレンドモード（通常・乗算・スクリーン・オーバーレイ・比較暗・比較明・加算・差の絶対値）、下のレイヤーと結合、クリア、複製、反転、移動、リネーム、表示切替、並び替え（最後の 1 枚削除ガード付き）。
- **パレット**: 作品ごとに独立コピーを保持（最大 256 色）、HSV / RGB / HEX スライダー＋直接数値・HEX 入力、6種の初期パレットライブラリ同梱（最後の 1 個削除ガード付き）。

### 5. UI サイズ調整・多言語・PWA 完全オフライン対応（v2）
- **UI サイズ調整**: 設定画面に「コンパクト / 標準 / 大きめ」の 3 プリセットと、全体倍率・アイコンサイズ・ボタン高さ・文字サイズ・色マスサイズ・チェックボックスサイズ・要素間隔・下部「描く」ボタン高さ(%) の 8 個別スライダー＋初期値リセットを搭載。
- **3言語リアルタイム切替**: 日本語 (`ja`) / English (`en`) / 한국어 (`ko`)。
- **ストレージ & 環境パック (`.zip`)**:
  - Dexie (IndexedDB) による確定データの自動保存、疎ピクセル差分 (`PixelPatch`) による作品別 Undo/Redo 履歴、`navigator.storage.persist()` 永続化リクエスト＆使用量可視化。
  - ロスレス整数倍率 PNG 書き出し（`1x` 常時選択可、最大 `2000px` 以下、透過維持）。
  - 全作品・全レイヤー・パレット・設定・UIサイズ・並び順・Undo/Redo 履歴を一括保存／事前検証付きアトミック復元する **環境パック ZIP**。
- **完全オフライン PWA**:
  - `manifest.webmanifest` (`display: standalone`)、カスタムドット絵 PNG アイコン一式（`32`, `180 apple-touch-icon`, `192`, `512`, `512 maskable`）。
  - ビルド時に全 HTML / JS / CSS / ローカルフォント (`.woff2`/`.woff`) / アイコンをプリキャッシュする Service Worker (`dist/sw.js`) を自動生成。IndexedDB データを一切消去せずオフライン起動・更新が可能。

## データアーキテクチャ

- **データベース**: Browser IndexedDB (`Dexie`, DB名: `dotdot_pixel_studio_v1`)
  - `projects`: 作品メタデータ、キャンバス寸法、作品専用パレット、合成サムネイル PNG バイト列、手動並び順
  - `layers`: レイヤー構造、表示/不透明度/ブレンドモード/クリッピング属性、生 RGBA バッファ (`ArrayBuffer`)
  - `histories`: 作品ごとの疎ピクセル差分 (`PixelPatch`) シリアライズ済み Undo/Redo スタック
  - `palettes`: パレットライブラリ（初期 6 種＋ユーザー保存パレット）
  - `settings`: テーマ、言語、グリッド、UIサイズ設定 (`UiSizeConfig`)、履歴上限など

## 開発・ビルド・テスト手順

```bash
# 依存パッケージのインストール
npm install

# TypeScript 厳格型チェック
npm run typecheck

# Vitest 単体・結合・UI E2E テスト実行（全6スイート・31テスト）
npm test

# 本番ビルド（PWAドット絵アイコン生成 → TypeScript/Viteビルド → オフラインSW生成）
npm run build

# ローカルプレビュー（Cloudflare Pages 静的配信互換）
npx wrangler pages dev dist --ip 0.0.0.0 --port 3000
```
