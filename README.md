# dotdot — Pixel Art Studio (v2.6.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵＆ピクセルアニメーション制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要です。レトロなドット絵の質感（完全影ゼロ設計・2px枠線・落ち着いた発色）を守りながら、**優しい系・リッチ系・都会的（アーバン／シティポップ）系・レトロ純喫茶／深緑／CRT端末系**など多彩な世界観から選べるマルチテーマ（ライト6種・ダーク6種）、全数字の `DotGothic16` ドット絵フォント統一・全スライダーの `<PixelSlider />` ドット絵UI統一・全アイコンのピクセル調統一、広いキャンバス領域と厳格な1行パレットバーを維持したまま、省メモリ・高速な **1バイト・インデックスカラー基盤** による制作体験を提供します。

## 最新アップデート（v2.6.0）の主な変更点

### 1. 1バイト・インデックスカラーエンジンへの全面移行（メモリ約1/4化）
- すべてのセルバッファ（`CelBufferRecord`）およびレイヤーバッファ（`LayerPixelRecord`）を従来の4バイトRGBAから **1ピクセル1バイトの固定インデックス配列 (`Uint8Array`)** へ移行（`0..254`: 不透明パレット色最大255色、`255`: 透明色 `TRANSPARENT_INDEX`）。
- **固定インデックス（`colorTable`）と表示順（`displayOrder`）の完全分離**: パレットのスウォッチ並び替え・知覚順ソートを行ってもピクセル配列の書き換えは一切発生せず、絵の色が崩れません。またパレットスロットの色変更は即座にそのインデックスを参照する全フレーム・全レイヤーのドットへ反映されます。
- **使用中パレット色の安全な削除＆置換UI**: 作品内で使用されているパレット色を削除する際は、参照ピクセル数を自動検出し、別のパレット色または透明へ一括置換した上で1ステップの Undo / Redo で復元できる確認ダイアログを表示します。
- **スポイト255色上限保護**: パレットが上限255色に到達している状態で合成色等をスポイトした際、既存の固定スロットを上書き破壊せず最も近い登録色を選択して通知します。

### 2. レジューム対応・容量安全な RGBA → インデックスカラー自動マイグレーション（Dexie v5）
- 既存の RGBA 作品を1作品ずつ順番に `indexed-v1` へ移行。変換前に `migrationStates` テーブルへ元データのバックアップを保存し、万一のブラウザ中断や容量不足（`QuotaExceededError`）発生時も元データを決して失わず安全にロールバック・再開します。
- 255色を超える作品には CIELAB 空間での知覚的メディアンカット減色を、半透明画素を含む作品には 4×4 Bayer アルファディザ近似を適用し、設定画面にて変換前後の比較プレビュー（Before / After）を確認できます。
- **環境パック ZIP v2 / v1 両対応**: 新形式（Format Version 2: 1バイト・インデックスカラー＋固定テーブル保持）での書き出し・復元に加え、旧形式（Format Version 1: RGBA）の環境パック ZIP も読み込み時に自動でインデックスカラーへ安全変換して復元します。

### 3. 多彩なレトロ・マルチテーマシステム（ライト6種 × ダーク6種）
- 標準の **ライト / ダーク / システム連動** のシンプルさとドット絵のレトロ感（影ゼロ・2px枠線・目に優しいコントラスト）を守りつつ、設定画面の「テーマカラーを詳しく設定」トグルから個性豊かなテーマを選択できます。
  - **ライト系（6種）**: ラベンダー・クリーム（優しい・標準） / ピーチ・コットン（優しい・桃色紙） / ミント・ポケット（爽やか・携帯ゲーム機風） / アンティーク・ブラス（リッチ・真鍮とボルドー） / アーバン・コンクリート（都会的・クールブルー） / レトロ純喫茶（琥珀コーヒー・マスタード）
  - **ダーク系（6種）**: ダスク・プラム（優しい夜・標準） / ロイヤル・ベルベット（リッチ・深紅と金） / トーキョー・シティポップ（都会的・ネオン） / アーバン・グラファイト（都会的・モノトーン） / フォレスト・アポセカリー（優しい深緑・薬草棚） / アンバー・CRT（レトロ端末・琥珀ブラウン管）

### 4. スタンプ・カスタムブラシ機能の廃止とUI整理
- UIのシンプルさと1バイト・インデックスカラー設計の一貫性を保つため、旧ピクセルスタンプ／パターンブラシ機能および関連モーダルを廃止し、ツール・設定画面をすっきり整理しました（過去の環境パック互換用スキーマのみ安全に保持）。

## 主要制作・入出力機能

- **静止画（1フレーム）× アニメーション（Nフレーム）統合セルアーキテクチャ & 後付けリンクセル (`LinkCelModal`)**
- **シンメトリー編集（左右・上下・4方向対称）& タイルプレビュー（3×3 / 5×5）& シームレス端折り返し編集**
- **8bpp インデックスカラー Aseprite (`.ase` / `.aseprite`) オフライン入出力（リンクセル双方向保持）**
- **WebGPU リアルタイムカメラドット絵取り込み (`CameraCaptureModal` / `webgpuCamera.ts`)**: 大画面カメラファインダー・大型シャッターボタン・背景のリアルタイム映像が透けて見える半透明折りたたみ設定オーバーレイ・WGSL Compute + Nearest-Neighbor Render パイプライン・CIELAB 固定/自動パレット（8〜255色・フレーム間ちらつき防止ロック）・「おまかせ / くっきり / レトロ（4×4・8×8 Bayer）」ディザリング・Canvas 2D 誠実フォールバック（完全端末内処理・外部送信ゼロ）
- **ワンボタン統合ファイルインポート (`UnifiedImportModal`)**: ファイル先頭シグネチャ（マジックバイト）と拡張子から PNG / GIF89a・87a / Aseprite (`.ase` / `.aseprite`) を自動判別して1つのボタンから読み込み（PNG `dotdot-meta`・GIF `DOTDOTMT1.0` 元ドット解像度復元対応）
- **多形式エクスポート (`UnifiedExportModal` & `multiFormatExport.ts`)**:
  - **静止画出力（「画像を出力」・デフォルト PNG）**: PNG / SVG (`crispEdges` ベクタードット絵) / WebP / BMP (32bit BGRA) / JPEG (背景色指定) / ICO (最大256px ファビコン) / Aseprite (`.aseprite`)
  - **アニメーション出力（「アニメーションを出力」・デフォルト GIF）**: GIF89a / アニメーションSVG (CSS `@keyframes` ベクター動画) / スプライトシート (PNG + JSON) / 連番PNG ZIP / Aseprite (`.aseprite`)
  - **「このフレームを出力」（編集画面・2フレーム以上時）**: 編集中アニメーションの現在フレーム単体を PNG / SVG / WebP / BMP / JPEG / ICO として書き出し
- **作品閲覧画面 (`ProjectDetailPage`) のアニメーション自動再生 & 表示最適化**: 複数フレーム作品は閲覧画面でフレーム時間・再生方向・ループ設定に従って自動アニメーション再生し、単一フレーム作品では不要なフレーム数表示やスプライトシート出力ボタンを非表示化
- **パレット高機能ツール (`PaletteToolsModal`) & Lospec 公式 API パレット読込**: 普段の1行パレットバーやパレットシートのシンプルさを保ったまま、1つの「パレット機能」ボタンから開く `document.body` ポータルモーダル（タイトルバー・×ボタン・モード切替タブ常時固定、内部スクロール）で **2色間のCIELAB知覚的グラデーション（中間色1〜7色）一括生成**、**ドット絵向け色相シフト付きハイライト／シャドウ追加**、**補色・トライアド・類似色ハーモニー追加**、**未使用パレット色の一括整理（1ステップUndo対応）**、知覚順並べ替え、色使用分析、リンクセル維持の色置換を実行可能
- **同色選択（初期モード・4/8近傍）＋矩形・楕円選択・動く境界点線（マーチングアンツ）・画面外領域保持の選択移動・作品間コピー＆ペースト（自動パレットリマップ対応）**
- **10言語プルダウン選択（`<PixelSelect />`） & ブラウザ言語の自動初期設定**: ドット絵制作コミュニティの多い **10言語**（日本語・英語・韓国語・簡体字中国語・繁体字中国語・スペイン語・ポルトガル語・フランス語・ドイツ語・ロシア語）をドット絵プルダウンUIから選択・自動判定可能（未対応言語環境は英語 `en` に安全フォールバック） & **PWA オフラインキャッシュ (`dist/sw.js`)**

## データ構造・ストレージ設計

- **保存先**: ブラウザ内 IndexedDB (`Dexie` `DotDotDatabase` **v5**) — 外部サーバー・クラウドDB不使用
  - `projects`: 作品メタデータ（`pixelFormat: 'indexed-v1'`, `migrationReport`）・レイヤー構成・パレット（`colorTable`, `displayOrder`, `originalDisplayOrder`）・タイムライン（`frames`, `cels`）
  - `celBuffers`: セル単位のユニーク 1バイト・インデックスカラーバッファ (`${projectId}:${celId}`)
  - `layerPixels`: アクティブフレーム投影および後方互換用 1バイト画素ストア
  - `histories`: 1バイト差分パッチ・構造スナップショット・パレット遷移を含む Undo/Redo 履歴
  - `migrationStates`: RGBA → インデックスカラー移行時のレジューム＆ロールバック用保護ストア（v5 新設）
  - `palettes`: カスタム＆Lospec インポートパレット（最大255不透明色）
  - `settings`: UI スケール・テーマ＆サブテーマ（`lightThemeVariant`, `darkThemeVariant`）・言語・履歴上限・各種初期値

## 開発・ビルド・テスト手順

```bash
# TypeScript 厳格型チェック
npm run typecheck

# Vitest 単体・結合・UI E2E テスト実行（全19スイート・90テスト）
npm test

# 本番ビルド（PWAアイコン生成 → TypeScript/Viteビルド → オフラインSW dist/sw.js 生成）
npm run build

# ローカルプレビュー（Cloudflare Pages 静的配信互換）
npx wrangler pages dev dist --ip 0.0.0.0 --port 3000
```
