# dotdot — Pixel Art Studio (v2.1.0)

**dotdot** は、100% ブラウザローカル（IndexedDB）かつ完全オフライン動作（PWA）に対応した、スマートフォン親指操作ファースト・PCフル対応の本格ドット絵制作 Web アプリケーションです。

外部サーバーへの作品データ送信やアカウント登録は一切不要で、低彩度カーボン×レトロデジタルツール調のフラット UI のもと、最大 256×256px・50 レイヤー（非破壊オフキャンバス画素保持・複数レイヤー一括移動対応）・透明色スロット・9方向アンカーリサイズ・ディザリング・ピクセルパーフェクト直線/3次ベジェ曲線・非破壊図形回転・長辺最大 4000px（初期選択 約2000px）PNG 出力＆OS共有シート・環境パック ZIP バックアップまで一貫して提供します。

## 主な実装済み機能（Phase A 統合完了）

### 1. フラット・カーボンレトロ UI & iOS PWA 対応
- **完全ゼロシャドウのフラットピクセルデザイン**: ダーク／ライト両対応、段積みピクセル枠と明確なチェックマーク・二重枠による状態表現。
- **iOS スタンドアロン PWA 上部プログレッシブブラー対策 (`IosPwaTopBlurFix`)**: ホーム画面追加起動時の上部ぼかしを抑止。
- **デバイスピクセル整数スナップ描画**: 右端・下端の白い隙間を出さない鮮明なキャンバス描画と拡大率連動の内側ピクセルグリッド、アニメーション付きマーチングアンツ、右上統合ステータスバッジ。
- **誤タップ防止ボタン配置**: 未確定操作の中断・キャンセル・破棄ボタンを右端へ統一配置。

### 2. 透明色スロット & 描画ツール強化
- **専用「透明色」スロット (`TRANSPARENT_COLOR_INDEX = -1`)**:
  - パレットバーおよびパレットシートの最左端に固定配置（256色上限の対象外・削除/色変更/並べ替え不可）。
  - ペン・塗りつぶし（4/8方向）・グラデーション塗り・直線・ベジェ曲線・図形・ディザリング（`#` 画素のみ透明化、`.` 画素は元色を保持）すべてで `RGBA(0,0,0,0)` として一貫動作。
  - スポイトで `alpha === 0` の画素を取得した際は自動的に透明色スロットを選択。
- **直線ツール & キャンバス外終点サポート**:
  - 直線ツールのサイズ・形状（四角/丸）・ディザ・ピクセルパーフェクトがカーソル表示とライブプレビューに即時反映。
  - 直線・ベジェ曲線・矩形・楕円・グラデーション塗り・範囲選択でキャンバス外へのポインタドラッグ終点指定に対応（全体ジオメトリ計算後にキャンバス範囲でクリッピング）。
- **スポイトの「二回タップで起動」**:
  - デフォルト ON（IndexedDB に保存、ツール詳細および設定画面で切替可能）。同じ画素マスを約 300ms 以内に素早く 2 回タップすると誤描画を残さずに色（透明含む）を取得し、直前のツールへ自動復帰。
- **選択範囲の縁取り色を作品パレット内に限定**:
  - 縁取り色は現在の作品パレット登録色スウォッチからのみ選択可能（透明色は除外、パレット変更時も自動フォールバック）。

### 3. 共通サイズプリセット & 9方向アンカーリサイズ
- **標準5種プリセット統一**: 新規作成とキャンバスサイズ変更の両方で `16×16` / `32×32` / `64×64` / `96×96` / `128×128` の5種を共通表示（削除不可）。
- **カスタムサイズプリセット**: 任意の幅×高さ（`1〜256px`、長方形可）を名前付きで登録・編集・削除・並べ替え可能（重複サイズ防止、IndexedDB & 環境パック ZIP に保存）。
- **9方向リサイズアンカー**: `3×3` ドット絵セレクタ（初期選択は中央 `'center'`）により全レイヤーの相対位置と画面外画素を保ったまま一括リサイズ。縮小時に表示範囲外へ出る画素がある場合は事前に注意を表示。

### 4. レイヤー管理・複数選択一括移動・`±1` スライダー
- **レイヤー名編集時テキスト全選択**: リネーム開始時に既存レイヤー名を自動全選択（`Enter` 確定 / `Escape` キャンセル / 空文字拒否）。
- **複数レイヤーチェック選択 & 一括移動**:
  - アクティブ描画レイヤー (`activeLayerId`) とは独立したチェックボックスを各行に配置。
  - 1枚以上チェック時に選択枚数・選択解除・キャンバス上での非破壊**一括移動**（相対位置・画面外画素保持、Undo/Redo 対応）およびコンパクトな一括複製/結合/削除を表示。
- **`±1` ステップボタン付き `PixelSlider`**: すべてのスライダーに最小/最大値で自動 `disabled` になる `[-]` / `[+]` ボタンを併設。設定画面にはリアルタイム UI サイズプレビューを搭載。

### 5. 作品一覧 → 作品閲覧画面 → 編集画面の導線 & PNG出力・バックアップ通知
- **閲覧ファースト導線**: 作品一覧 (`/`) のタイルタップ時は必ず作品閲覧画面 (`/project/:id`) を開き、「編集する」ボタン押下時のみ `/editor/:id` へ遷移（`<ViewTransition>` 共有要素アニメーション維持）。
- **PNG 書き出し（最大 4000px / 初期選択 約2000px）& OS 共有シート**:
  - 長辺最大 `4000px` までの整数倍ニアレストネイバー拡大に対応し、初期倍率は長辺 `2000px` に最も近い整数倍（例：`256×256 → 8x`、`80×80 → 25x`）を自動選択。
  - 独立した「ダウンロード」ボタンと「共有」ボタン（Web Share API `navigator.canShare` / `navigator.share` 対応、非対応環境フォールバック案内付き）に加え、iOS 長押し保存を阻害しないネイティブ `<img>` プレビューを搭載。
- **30日 / 7日 環境パックバックアップ通知**:
  - 前回の環境パック ZIP エクスポート（未実施時は最初の作品作成）から 30 日経過後にギャラリー上部で控えめに通知。「今すぐバックアップ」で ZIP 出力＆「最終エクスポート日時」更新、「後で通知」で 7 日後再通知（PNG 出力では最終エクスポート日時を更新しない）。

## Favicon・PWA アイコンの構成と差し替え手順

現在のリポジトリにおけるアイコン関連ファイルは以下の構成で管理されています。

1. **参照元 HTML (`index.html`)**
   - ブラウザタブ用 PNG Favicon (`32×32`): `/icons/favicon-32.png`
   - ブラウザタブ用ベクター Favicon: `/favicon.svg`（実ファイル: `public/favicon.svg`）
   - iOS ホーム画面アイコン (`180×180`): `/icons/apple-touch-icon.png`
   - Web App Manifest: `/manifest.webmanifest`
2. **PWA マニフェスト (`public/manifest.webmanifest`)**
   - `/icons/favicon-32.png` (`32x32`)
   - `/icons/apple-touch-icon.png` (`180x180`)
   - `/icons/icon-192.png` (`192x192`, `purpose: "any"`)
   - `/icons/icon-512.png` (`512x512`, `purpose: "any"`)
   - `/icons/icon-maskable-512.png` (`512x512`, `purpose: "maskable"`)
3. **ビルド時の自動生成スクリプト（重要注意点）**
   - `package.json` の `"build"` スクリプト先頭で `node scripts/generate-pwa-icons.mjs` が毎回実行され、`public/icons/` 配下の5つの PNG をスクリプト内の 16×16 ドット定義 (`GRID_16`) から再生成・上書きします。
   - **差し替え手順**:
     - 方法A（ドット絵定義で差し替える場合）: `scripts/generate-pwa-icons.mjs` 内の `PAL` / `GRID_16` と `public/favicon.svg` を編集して `npm run build` を実行する。
     - 方法B（任意の PNG 画像ファイルを直接配置する場合）: `package.json` の `"build"` から `node scripts/generate-pwa-icons.mjs && ` を外したうえで、`public/icons/` の各サイズ PNG（`32×32`, `180×180`, `192×192`, `512×512`, maskable `512×512`）と `public/favicon.svg` を差し替え、`npm run build` を実行する（`scripts/build-sw.mjs` が新ファイルのハッシュを `dist/sw.js` に自動反映します）。

## ルーティング一覧（Entry URIs）

| パス | 画面 | 説明 |
| :--- | :--- | :--- |
| `/` | `GalleryPage` | 起動時の標準ホーム（作品一覧・空状態CTA・新規作成・ソート・長押し並び替え・バックアップ通知） |
